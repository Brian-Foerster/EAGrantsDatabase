# EA Grants Database — Public Data API

The site is a static export, so the "API" is a set of versioned JSON files
served straight from the site. No key, no rate limit, no server — just fetch a
URL. Everything below is generated by `npm run build:data` and published to the
live site on every deploy.

**Base URL:** `https://www.eagrantsdatabase.org/data/`

## Versioning

`metadata.json` carries a `schemaVersion` (currently **`1.0`**). The contract:

- **Minor bump** (`1.0` → `1.1`): additive, backward-compatible (new optional
  fields, new endpoints). Existing fields keep their meaning.
- **Major bump** (`1.x` → `2.0`): a field was removed, renamed, or its meaning
  changed. Pin to a major version and check `schemaVersion` before parsing.

Read `metadata.json` first and branch on `schemaVersion` if you cache or
persist parsed data.

## Endpoints

### `metadata.json`

The index. Read this first.

```json
{
  "schemaVersion": "1.0",
  "totalGrants": 7707,
  "totalAmount": 7608756199.97,
  "grantmakers": ["Coefficient Giving", "GiveWell", "..."],
  "categories": ["LTXR", "GH", "AW", "Meta", "Policy", "Science", "Other"],
  "dateRange": { "earliest": "2012-07-01", "latest": "2026-12-01" },
  "lastUpdated": "2026-09-03T02:05:09.361Z"
}
```

`totalAmount` counts regrants **net** of the tracked upstream funding that
already includes them (see the regrant note below), so it is not simply the sum
of every grant's `amount`.

### `grants.min.json`

The full grant list — one array, ~3.3 MB, ~7,700 objects. This is the primary
dataset.

```json
[
  {
    "id": "cg-alg-00627",
    "title": "Malaria Vaccine Meeting at ASTMH Conference",
    "recipient": "The Kids Research Institute Australia",
    "amount": 55000,
    "currency": "USD",
    "date": "2026-12-01",
    "grantmaker": "Coefficient Giving",
    "category": "Other",
    "focus_area": "Infectious Diseases",
    "fund": "Infectious Diseases",
    "url": "https://...",
    "description": "Focus area: Infectious Diseases"
  }
]
```

| Field | Type | Notes |
|---|---|---|
| `id` | string | Stable within a build; not guaranteed stable across re-scrapes. |
| `title` | string | Grant title. |
| `recipient` | string | Recipient organization/person. |
| `amount` | number | In `currency` units. The grant's own face value. |
| `currency` | string | ISO code, almost always `"USD"`. |
| `date` | string | `YYYY-MM-DD`. Day is often the 1st when only month/year is published. |
| `grantmaker` | string | One of `metadata.grantmakers`. |
| `category` | string | One of the 7 codes in `metadata.categories`. |
| `focus_area` | string | Raw source label (finer than `category`); may be `""`. |
| `fund` | string | Source funding vehicle/program (e.g. "Long-Term Future Fund"); may be `""`. |
| `url` | string | Link to the source grant page; may be `""`. |
| `description` | string | May be `""`. |
| `is_residual` | boolean? | Present and `true` only for computed gap-fill entries (an annual-total residual, not an itemized grant). Omitted otherwise. |
| `regrant` | boolean? | Present and `true` for regrants (BlueDot, Manifund). Omitted otherwise. |
| `regrant_of` | string[]? | Present with `regrant`: names of the upstream funders whose money is being re-granted. |

**Regrant accounting:** a grant with `regrant: true` is money passed through a
regrantor. To avoid double-counting the funder → regrantor → recipient chain,
`metadata.totalAmount` and the aggregates below count regrants *net* of tracked
upstream funding to that regrantor. If you sum `amount` yourself and want to
match our totals, exclude regrants whose upstream is already in your sum.

### `agg/by_funder.json`

```json
[{ "funder": "Coefficient Giving", "count": 3403, "total": 4641416760, "average": 1363919.12 }]
```

### `agg/by_year.json`

```json
[{ "year": 2012, "count": 2, "total": 1100000, "average": 550000 }]
```

### `agg/by_category.json`

```json
[{ "category": "GH", "count": 1054, "total": 3295815100.54, "average": 3126959.30 }]
```

### `agg/by_year_category.json`

```json
[{ "year": 2012, "category": "GH", "count": 1, "total": 1000000, "average": 1000000 }]
```

### `agg/by_year_month.json`

```json
[{ "yearMonth": "2012-06", "count": 1, "total": 100000, "average": 100000 }]
```

### `recipient-orgs.json` (Org Financials)

A separate dataset powering the Org Financials view: per-organization financial
statements (income / expenses / assets / liabilities by fiscal year), assembled
from 990 filings and charity registers.

```json
{
  "generated_at": "...",
  "org_count": 000,
  "filing_count": 000,
  "orgs": [
    { "name": "...", "legal_name": "...", "category": "...", "detail_category": "...",
      "country": "...", "currency": "USD", "source": "...", "ein": "...", "cc_number": "...",
      "notes": "...", "fy_end_month": 0, "grant_names": ["..."], "filings": [ /* per-year */ ] }
  ]
}
```

### `grant-writeups.json`

Long-form writeups for a subset of grants, keyed by a stable content key
(`recipient|amount|YYYY-MM`) rather than grant `id`, so the text survives
re-scrapes.

## Recipes

```js
// All SFF grants ≥ $1M, newest first
const grants = await (await fetch('https://www.eagrantsdatabase.org/data/grants.min.json')).json();
const sff = grants
  .filter(g => g.grantmaker === 'SFF' && g.amount >= 1_000_000 && !g.is_residual)
  .sort((a, b) => b.date.localeCompare(a.date));

// Totals by year, straight from the aggregate (no need to load every grant)
const byYear = await (await fetch('https://www.eagrantsdatabase.org/data/agg/by_year.json')).json();
```
